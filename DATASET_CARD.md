# Dataset Card

## Name
Repository Intelligence Catalog — Curated Demo

## Scope
Public GitHub repository metadata, not repository source code.

## Current sample
15 repositories across five developer-tool categories.

## Intended uses
- repository discovery demos
- retrieval/ranking experiments
- license/freshness filtering examples
- coding-agent context selection research

## Not intended for
- inferring security from stars
- claiming license compatibility without reviewing license text
- personal profiling of contributors
- mirroring repository source code

## Limitations
The sample is curated and is not statistically representative of GitHub.
