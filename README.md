# Repository Intelligence Catalog

**Evidence-backed repository discovery for developers and AI coding agents.**

Repository Intelligence Catalog turns repository discovery into a controlled reuse workflow:

**Need → Search → Evidence → REUSE / ADAPT / REFERENCE / AVOID**

## Verified release scope

This public release contains:
- a resumable public-repository metadata harvester;
- a bounded local SQLite/FTS index;
- a query CLI;
- repository schema and methodology;
- a **15-repository curated metadata demo** across five developer-tool categories;
- security, attribution and data-rights guidance.

The private canonical corpus and repository source code are **not** included.

## Evidence boundary

The validated engineering pilot has enumerated **1,200 repositories** with checkpoint/resume and Drive-backed cold storage.

That 1,200-row pilot is **not** a claim that the full GitHub repository universe has been analyzed.

The public demo contains 15 selected repositories and is intentionally small enough to audit.

## Reuse discipline

A public GitHub repository is not automatically reusable open-source software. Before integration, revalidate:
- current license;
- archived/deprecated status;
- maintenance activity;
- dependency/security risk;
- project fit.

Stars and forks are discovery signals, not proof of quality.
