# OpenRepo Intelligence

**Project-first open-source intelligence for developers and AI agents.**

OpenRepo Intelligence turns GitHub's repository universe into a controlled reuse workflow:
**need → search → shortlist → license/maintenance/security checks → REUSE / ADAPT / REFERENCE / AVOID**.

## Current verified state
- 1,200-repository resumable enumeration pilot
- Drive-backed cold storage + bounded local SQLite FTS index
- 50-repository curated live showcase across MCP, RAG, AI Agents, Browser Automation, and Programmatic Video
- Obsidian promotion layer for project-relevant repository cards
- zero paid API/storage operations in the current pipeline

## What this repository will publish
Code, schema, methodology, small public samples, reproducible benchmarks, and release manifests.
The canonical bulk corpus is kept outside Git because generated large datasets do not belong in Git history.

## Important
A public GitHub repository is not automatically open source. Reuse requires license verification.
Repository code is **not** redistributed by this dataset.

## Status
Private staging / pre-launch. Public claims must match a dated evidence manifest.
