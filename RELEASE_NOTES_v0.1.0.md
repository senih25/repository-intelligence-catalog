# v0.1.0

Initial public release of Repository Intelligence Catalog.

## Included
- resumable public-repository metadata harvester
- bounded SQLite/FTS local index
- repository search CLI
- repository schema and methodology
- 15-repository curated metadata demo
- Apache-2.0 code/documentation license
- separate metadata rights and attribution notice

## Evidence boundaries
- engineering pilot validated checkpoint/resume over 1,200 repository records
- public demo contains 15 curated repository metadata records
- no repository source code is redistributed
- repository descriptions/topics/contributor data are excluded from the public dataset

## Reuse rule
Public visibility is not proof of license compatibility or project fit. Revalidate the source repository before reuse.

## Cost
The validated pipeline was built and tested without paid API or storage operations.
