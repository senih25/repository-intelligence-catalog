# Publishing Checklist

- [ ] Product name/trademark review completed.
- [ ] Code/documentation license selected.
- [ ] Dataset license selected.
- [ ] GitHub attribution/terms reviewed.
- [ ] No secrets or private paths in public files.
- [ ] Sample contains metadata only.
- [ ] README metrics revalidated on release day.
- [ ] Security/dependency scan passes.
- [ ] Public repository visibility explicitly approved.
- [ ] Kaggle dataset visibility explicitly approved.
- [ ] Release evidence stored in Obsidian.
