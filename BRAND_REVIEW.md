# Brand Collision Review

## Public name
**Repository Intelligence Catalog**

## Result
Release-day web/GitHub collision scan found generic uses of the phrase "repository intelligence", but no obvious exact product-title match for "Repository Intelligence Catalog".

An earlier working name was retired before public release because its root term is already used by multiple active repository-management and AI-powered open-source discovery projects.

## Boundary
This is a practical naming-collision scan, **not** a legal trademark clearance or legal opinion.

## Release rule
Public-facing files use **Repository Intelligence Catalog**.
