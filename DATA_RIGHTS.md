# Data Rights and Attribution

## Scope
The Apache-2.0 LICENSE in this repository applies to the original software and documentation authored for Repository Intelligence Catalog.

The curated CSV sample is a separate metadata compilation.

## Curated metadata sample
The public sample contains:
- our derived `category` field;
- factual GitHub repository identifiers and URLs;
- factual snapshot metadata such as language, license identifier, popularity counts, timestamps, archived state and default branch.

We do not claim ownership of third-party repository names, trademarks, licenses, or underlying repository content.

No repository source code is redistributed.

## Source
Repository metadata is retrieved from GitHub interfaces and is subject to GitHub's Terms of Service and the rights of the respective repository owners.

Source: https://github.com/
